# MODUX Creative | Site institucional

Site da **MODUX Creative**, agência de branding, sites e sistemas. Apresenta serviços, posicionamento e um portfólio com páginas de case em vídeo.

🔗 **Site:** [moduxcreative.com](https://www.moduxcreative.com)

## Destaques

- Hero com vídeo e animações de entrada com Framer Motion
- **Páginas de case** (Biomaxx, Nørxx, Di Amalfi, Casa Martinho) com vídeo de abertura e galeria em marquee
- **Vitrine de sites** desenvolvidos (Goiás FA, Aurora's, piriExtra e outros)
- Formulário de contato com rota de API própria (`app/api/contact`)
- Layout responsivo com Tailwind CSS

## Stack

Next.js (App Router), React, TypeScript, Tailwind CSS, Framer Motion e deploy na Vercel.

## Como rodar

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```
